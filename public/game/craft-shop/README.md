# Tiệm Bách nghệ — product artwork

Six transparent product illustrations created with the built-in `image_gen` tool.
These are illustrative game assets, not photographs documenting a particular maker's products.
Each WebP is 560 × 440, quality 86, preserving alpha. No runtime image API is used.
`ProductArt` uses the same image for the shelf, orders and delivery tray.

Files: `pot.webp`, `silk.webp`, `basket.webp`, `fan.webp`, `hat.webp`, `dragonfly.webp`.

## Prompt set

Pot prompt:

> Use case: product-mockup. Create a single isolated game asset of a Vietnamese Bat Trang blue-and-white ceramic vase, realistically photographed, hand-painted cobalt lotus and vine ornament, warm ivory crackle glaze, subtle handmade surface, rounded pear-shaped body and slender neck, complete object centered with generous transparent padding, front three-quarter view, soft studio lighting, restrained contact shadow, crisp silhouette readable at 50 pixels. No text, no logo, no frame, no other objects. Output transparent background.

Shared prefix for the other five assets:

> Use case: product-mockup. A single isolated game asset, realistic handcrafted Vietnamese product photography, entire object visible and centered with generous transparent padding, front three-quarter view, soft warm studio lighting and restrained contact shadow. Clear recognizable silhouette at 50 pixels, rich material texture. No text, logos, watermark, border or additional objects. Transparent background.

Subject appended to that prefix:

- **silk:** A folded deep terracotta red Vietnamese silk scarf from Van Phuc, elegant soft folds with one trailing end, subtle woven golden floral jacquard, fine fringed hem, sheen and realistic fabric fibers.
- **basket:** A small round Vietnamese handwoven honey-colored rattan shopping basket from Phu Vinh with a single arching handle. Realistic interwoven rattan strips and woven rim, open top visible, complete handle and body.
- **fan:** An open Vietnamese handmade folding paper fan from Chang Son, semicircular ivory rice-paper leaf with subtle dark green bamboo foliage hand painting, clearly visible warm bamboo ribs converging at the bottom pivot, natural paper grain and creases.
- **hat:** A traditional Vietnamese non la conical palm-leaf hat, cream straw color, conical peak high in the center, fine concentric bamboo stitching clearly visible, softly curved wide elliptical brim, red silk chin ribbon subtly visible under brim.
- **dragonfly:** A Vietnamese handcrafted balancing bamboo dragonfly toy from Thach Xa, realistic thin split-bamboo wings painted vermilion red and mustard gold, slim bamboo body and long tapering tail, small round bamboo head, four long delicate wings distinctly visible, diagonal overhead three-quarter view, craft toy not a real insect.
